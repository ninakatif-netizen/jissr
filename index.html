Jissr · جسر

No abnormal result left behind.

One programme: abnormal HbA1c from screening. Jissr helps the patient understand the result in plain English or Arabic, get past what is stopping them, and book care. It gives the care team a list where every case has an owner, a due date and an honest status, and where a case can only be closed by a clinician with evidence.

If it fails–A pre-written message is used, so nothing breaks
  • Every patient message ends with “This is not a diagnosis.” The code adds it, so it cannot be left out.
  • AI text passes a safety filter first (no “you have diabetes”, no medicine advice, right language). If it fails, the pre-written text is shown.
  • The AI is sent only a band, a number and a barrier. It never receives a name or any patient detail.
  • A case closes only when a clinician gives a reason and written evidence. The rule is enforced in code, not just by a greyed-out button, and it is tested.
  • The AI provider sits behind one adapter, so moving to Azure OpenAI is a settings change.

What this prototype is not (yet)

  • All 30 patients are invented. Nothing real is stored; data stays in your browser.
  • The staff role switch is a demo. A real system would use proper sign-in (for example Microsoft Entra ID).
  • Reminders and calls are simulated. A real service would need UAE health-data compliance (DoH policy, ADHICS), Malaffi integration and patient consent management.
  • Follow-up windows (30 days / 14 days / 48 hours) are proposals for a clinician to confirm.
  • Arabic text still needs review by a native-speaking clinician.
